# Calculadora em Python

Projeto desenvolvido em Python com o objetivo de praticar lógica de programação e conceitos fundamentais da linguagem.

## Funcionalidades

- Soma de múltiplos números.
- Subtração de múltiplos números.
- Multiplicação de múltiplos números.
- Divisão de múltiplos números.
- Validação de entradas inválidas.
- Tratamento de divisão por zero.

## Tecnologias utilizadas

- Python 3
- Google Colab

## Conceitos aplicados

- Funções
- Listas
- Estruturas de repetição (`while`)
- Estruturas condicionais (`if`, `elif` e `else`)
- Tratamento de exceções (`try` e `except)

## Como executar

1. Instale o Python 3.
2. Baixe o arquivo `calculadora.py`.
3. Abra o terminal na pasta do arquivo.
4. Execute:

```bash
python calculadora.py
```
